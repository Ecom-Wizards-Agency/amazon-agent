# Traffic tables

Learn about Amazon Marketing Cloud (AMC) traffic tables, which contain records of your Amazon Ad media delivery, including impression, click, and view events.

Updated on Nov 19, 2025

**Tip:**We recommend using the Amazon Marketing Cloud data sources file to understand field information and definitions.

## Amazon DSP traffic tables

These tables contain inputs from all Amazon DSP campaigns from the ads accounts that have been added to this instance. They include records from ad product types such as Display, Online Video, Streaming TV, Audio, and others. Learn more about Amazon DSP traffic tables.

## Sponsored ads traffic table

**sponsored_ads_traffic**

This table contains impression events, click events, and video creative messages from Sponsored Products, Sponsored Brands, and Display campaigns. There will be 1 record per sponsored ads impression event and 1 record per click event originated from a sponsored ads campaign. Learn more about sponsored ads traffic.
