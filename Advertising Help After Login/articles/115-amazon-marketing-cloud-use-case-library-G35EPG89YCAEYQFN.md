# The use case library

The Use case library is a comprehensive collection of ready-to-use custom solutions and Amazon-authored SQL queries, also known as instructional queries (IQs). Amazon Marketing Cloud (AMC) users can either directly implement these solutions or modify the SQL code of an IQ to address common measurement and audience analysis needs.

Updated on Feb 23, 2026

In the **Use case library** you can explore top use cases for AMC from a repository of Amazon-authored SQL queries and solutions by our experts, to help you leverage common measurement and analytics use cases.

The Use case library helps you to quickly identify use cases, find query templates or solutions, build audiences, and generate insights directly in your AMC UI account. Each use case contains business context, usage instructions, and guidance on interpreting the results. Examples of use cases range from path to conversion analyses, to technical queries that review how to manipulate certain fields for your desired outcome.

## Sort and filter use cases

By default, the most recently added use cases are shown at the top of the results. You can also search for use cases alphabetically by title, or filter results based on attributes like:

- Features such as the AMC sandbox.
- Ad products such as Amazon DSP and sponsored ads.
- Use case categories such as Overlap analyses.
- Specific audiences you want to create.
- Point and click solutions to inform decisions like frequency management.
- Conversion types such as On-Amazon conversions.
- Tables used such as dsp_impressions.

## How to use the use case library

Select a use case that’s closest to your needs. AMC will list IQs and, in some cases, solutions. If an applicable solution comes up in the results, you can simply launch the solution and follow the on-screen instructions to derive insights. Otherwise, select an IQ, that’s closest to your requirement, then review the instructions, and the sample queries listed. Each sample query has an Open in query editor button that allows you to automatically load the query in the query editor. You can run the query as is or modify it to suit your requirements.

Queries may include optional updates that allow you to modify the query with your specific requirements. For example, the ability to define included campaigns, to assign campaigns to groups, or to filter results to specific ASIN values.

## No code templates

Some IQs may include a template that allows you to generate insights and audiences from your advertising signals without writing any SQL code. These no code templates (also known as “template analytics” and “template audiences”) may require campaign, ASIN, or other inputs to run. To view a list of available templates, filter by No code.
