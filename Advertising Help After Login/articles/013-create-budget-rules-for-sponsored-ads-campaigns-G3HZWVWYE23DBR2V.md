# Create budget rules for sponsored ads campaigns

Learn how to create and manage budget rules for your sponsored ads campaigns.

Updated on Mar 18, 2026

Budget rules allow you to set rules to increase daily budgets based on shopping events and campaign performance. You can learn more about budget rules before getting started.

## Create a budget rule

Follow these steps to create a budget rule

1. In the navigation side menu, click **Campaigns**.
2. Next to the campaign name that you want to add a rule for, click **More** and then **Edit Settings**.
3. Select **Budget rules**.
4. Click **Add budget rule**.
5. **Type:** choose schedule or performance .
6. **Date range**: select a special event or enter a custom start and end date. For special events, when setting up a rule, you can choose **Events**, then click the **drop-down arrow** to see the list of recommended promotional events.
7. **Rule recurrence:** choose daily to apply the rule every day, or weekly to select certain days for it to run.
8. **Hours of day** (schedule only): select daily for the rule to run all day, or choose a start and end time to only run it for part of the day. Hours of day scheduling for budget rules is currently only available in the US, CA, UK, IN, and JP marketplace.
9. **Performance metric** (performance only): choose your performance metric and threshold for increase.
10. Set your budget increase amount.
11. Click **Add budget rule**.

## Budget rule status

Once your budget rule is set, from Campaign manager, you can see the adjusted daily budget and rule status.

| Status | Details |
| --- | --- |
| Active | The rule is active and increased budget is used for budget enforcement for the day. |
| On hold | The rule is on hold as the performance criteria hasn't been met. |
| Paused | The rule is paused. |
| Upcoming | The rule will become active in future. |
| Expired | The rule has reached its end date. |
