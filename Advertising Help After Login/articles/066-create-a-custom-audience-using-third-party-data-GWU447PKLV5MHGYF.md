# Create a custom audience using third-party data

Use data collected off-Amazon to create custom audience segments.

Updated on Jun 16, 2026

## How to create an audience

Create an audience:

1. In the navigation side menu, click **Campaigns**.
2. Click **Audiences** in the side navigation.
3. Click **New audience**. Search and select **Hashed audience data** to create advertiser hashed audience.
4. Click **Your data**.
5. Click **Next** on the tile for the audience type you want to create (Amazon Ads Tag, Off-Amazon conversions, Hashed).
6. Follow the steps below according to your chosen audience type.

Your ad tag must be properly set up to create an audience based on it. Learn how to create an Amazon Ad tag.

1. Enter an audience and description
2. Create inclusion and/or exclusion rules Choose “match any” or “match all” from the first dropdown. Click “choose event” and search for your desired rule. Enter a lookback window
