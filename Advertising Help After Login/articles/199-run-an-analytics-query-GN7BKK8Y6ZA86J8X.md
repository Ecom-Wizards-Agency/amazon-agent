# Run an analytics query

Learn how to write an Amazon Marketing Cloud (AMC) analytics query.

Updated on Nov 19, 2025

There are various ways in which AMC can help you generate insights. These insights can help you better understand your optimal campaign reach and frequency, determine which combination of marketing channels deliver results, and review the total impact of your media campaigns across the marketing funnel.

- **Query editor.**The AMC query editor page allows you to compose queries, run them, and view the resulting report. You can use this page to create queries from scratch.
- **Use case library.** If you want to quickly find use-cases-focused query templates and solutions to generate insights, you can use the Use case library. Refer to Create analyses with use cases for guidance.
- **Projects.**View the results of your submitted measurement and audiences queries.
