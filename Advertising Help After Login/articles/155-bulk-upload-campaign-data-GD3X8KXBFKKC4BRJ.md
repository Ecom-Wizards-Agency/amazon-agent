# Bulk upload campaign data

You can upload your Amazon Attribution campaign metrics in bulk instead of creating them individually.

Updated on Aug 1, 2023

Before you get started with bulk upload, figure out which products to associate ahead of time. When preparing a bulk sheet, the products you select will apply to all campaigns. You also have an option to adjust products later in the settings. Alternatively, you can prepare separate bulk files if you want the campaigns created to include different products.

**Note:**Bulk operations feature is available for Google search and Facebook and Instagram ads campaigns in the Amazon Attribution console. It enables you to easily tag and measure up to 100,000 Google search keywords or 8,500 Facebook ads by uploading a single file.

To create Amazon Attribution campaigns in bulk:

1. Go to **Campaigns** and click **Create campaign.**
2. Select **Upload file to create in bulk** in Creation method**.** Choose this method for Google search and Facebook ads campaigns only. This option enables you to easily tag and measure up to 100,000 Google search keywords or 8,500 Facebook ads by uploading a single file.
3. Select **Publisher**.
4. **Download the bulk file template**to retrieve the bulk file. Go to **Instructions**tab of the downloaded template and follow the steps to create a report that includes the required columns listed in the template. Copy that information into your downloaded template.
5. Upload your completed bulk file template and ensure no errors. After you’ve completed your file, click **Choose a file** under **Bulk upload settings**. Once selected, the file will be immediately reviewed for errors. If you receive error messaging, correct these errors and reselect the file to be uploaded.
6. Select products. Under **Products**, you should see all the products you're selling on Amazon. We recommend selecting the specific products, and any associated variations, by selecting **Add variations**, featured in the campaign’s creative. If you don’t see the products you’re looking for, follow the instructions for managing brand-to-product mapping.
7. Finish campaign creation. Select **Create**to begin the tag creation process. This process will take roughly 10 minutes and you’ll be notified via email once complete. You can also check the progress on the Bulk created campaigns page. Once complete, the progress will change to **Completed**.
8. Download tags. Once the tag creation is completed, you’ll see an attribution tags file generated. Download the resulting bulk sheet, with the associated Amazon Attribution campaign information.
9. Upload tags to your Google Ads or Facebook Ads manager.
  1. In Google Ads, navigate to **Keywords**, select **More**, and click **Upload**.
  2. In Facebook Ads Manager, click the **Export & Import** menu icon and then click **Import Ads**.

After you download the tag sheets, save them locally for future reference. The attribution tag sheets have all required columns to be imported into the publisher’s interface. Please work with the publisher for assistance.

After you create tags for a campaign and you want to create more tags for the same campaign, just upload a new file. Even if your file contains ads you already uploaded before, any pre-existing tags will be reused and new tags will be created as needed. The processed file will contain a mix of old tags and new tags.
