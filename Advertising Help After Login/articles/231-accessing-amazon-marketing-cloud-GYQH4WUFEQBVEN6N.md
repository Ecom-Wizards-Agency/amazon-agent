# Accessing Amazon Marketing Cloud

Learn how to access Amazon Marketing Cloud (AMC)

Updated on Nov 18, 2025

You can access AMC directly from your Amazon Ads account. Through AMC, you can quickly analyze campaign performance and create high-intent audiences that improve advertising relevance and effectiveness. Access AMC in the left hand navigation bar in the Ads Console, under Measurement & Reporting

If you are a sponsored ads advertiser, you can use AMC instant access to automatically create an AMC instance associated with your sponsored ads account and start using AMC within minuteutes.

Otherwise, if you want the scope of your instance to include data from multiple advertisers or Amazon DSP advertisers, you will need to reach out to your AdTech AE or Partner to apply for access to AMC. After you apply for access, Amazon provisions an AMC account. Your account will be managed by a user your organization designates as the "AMC admin". Your organization's AMC admin can create instances and add advertiser ids to the instances. The admin can then add users to the account to view and analyze data in the assigned instance.

## AMC access methods

AMC provides 2 two different access points to generate insights: the AMC user interface (UI) and AMC application programming interface (API). The AMC UI is intuitive and easy-to-use, with several options to help you work with the instances assigned to your account. It allows you to run ad-hoc SQL queries and access the query executions results in the UI. The AMC API allows you to programmatically work with your instances to generate insights.

For more information about onboarding and using the AMC API, visit Get started with Amazon Marketing Cloud.

## Accessing the AMC user interface

When your organization's administrator invites you to their AMC account, you'll receive an invitation email. If you already have an AMC account, just click the link in the email to accept the invitation. But if you don't yet have an Amazon Ads account, follow these steps to create one:

- Access Amazon Ads and click Sign in to access the registration form.
- On the sign-up form, select the country that your advertising account is associated with.
- Select the ads product that your organization uses to fulfill its advertising needs.
- Type the email id that you use to access your Amazon Ads account and its corresponding password and click Sign in.

After you accept the invite and the terms and conditions displayed on first sign-in, you're eligible to be added to an instance within the account. By default, new users won't have access to any instances; the AMC admin must permission the user to instances as needed.

Once you're added to an instance, you'll see the instance in the AMC homepage. When you click the instance, AMC will render a workspace where you can query tables associated with your instance.

## The AMC user interface

AMC's user interface (UI) includes a variety of features to help you work, allowing you to explore use cases, run ad-hoc queries, and access the query results.

Once you've signed in, you'll see all instances associated with your AMC account.

This page lists the Instance name, Advertiser name, Instance ID, instance creation information, and a link to take you to the Instance info page. This page contains additional information about the instance, such as the IDs of the linked Amazon DSP and sponsored ads entities.

When you select an instance, the instance will open to the Use case library tab, which houses AMC's use cases. The Use case library is a repository of custom solutions and Amazon-authored SQL queries, referred to as instructional queries (IQs), that can help you leverage common measurement and analytics use cases. To learn more about the Use case library, visit Use case library.

The navigation menu at the top of the page also provides access to the other tabs in the AMC UI. To learn more about each tab, click each link from the list below:

- Query editor
- Audiences
- Paid features
