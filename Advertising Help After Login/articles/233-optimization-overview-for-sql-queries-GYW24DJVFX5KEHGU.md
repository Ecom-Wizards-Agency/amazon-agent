# Optimization overview for SQL queries

Optimizing the SQL code of your query can help you mitigate issues such as longer-than-expected run times or post-execution errors that occur when running complex queries or queries that run across long date ranges.

Updated on Nov 12, 2025

AMC supports use cases of varying complexity, and each AMC instance contains up to 12.5 months of your advertising records. SQL optimization is the process of improving the performance of a query by adjusting query elements to reduce execution time and resource usage while still producing accurate results. Queries can often be optimized for simplicity and efficiency by:

- Filtering records early in the query
- Eliminating redundant subqueries
- Optimizing JOIN conditions
- Optimizing the query’s order of operations

To learn more about optimizing queries, including some step-by-step walkthrough of common optimization techniques, refer to the How to optimize AMC SQL queries entry in AMC’s Use case library.
