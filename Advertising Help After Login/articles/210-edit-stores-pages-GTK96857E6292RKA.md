# Edit Stores pages

Stores can have one or more pages, and up to 3 levels of page hierarchy. The top-level page is your homepage. Additional subpages can be added one or 2 levels below the homepage.

Tip: You can use the Brand Store Builder Agent to create your brand store pages quickly using AI-generated content and layouts that follow brand store best practices.

Was this video helpful? Select feedback

This page provides information on how to edit existing Stores. If you’re creating a new store, visit Create your Store for detailed steps on creating your store.

When editing your store, make sure to follow the Stores Content Guidelines and Acceptance Policies. Your store must meet these requirements to pass the moderation review and go live. The moderation review process is usually completed within 24 hours, but it may take up to 3 business days. Learn more about Stores moderation.
