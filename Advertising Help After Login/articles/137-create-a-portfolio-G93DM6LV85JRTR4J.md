# Create a portfolio

Create a portfolio to simplify campaign management.

Updated on Aug 7, 2026

To create a portfolio:

1. Navigate to the campaign manager.
2. Open **Portfolios**from the left navigation panel
3. Click **Create portfolio.**
4. In the pop-up window, name your portfolio and click **Create a portfolio**. Give the portfolio a name that is meaningful to you and has a consistent format to help you find it and differentiate it from other portfolios.

**Note:**

- A campaign can only belong to 1 portfolio at a time. To learn how to move a campaign to a different portfolio, see Edit your portfolios.
