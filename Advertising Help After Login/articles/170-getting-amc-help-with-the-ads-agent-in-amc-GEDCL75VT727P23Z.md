# Getting AMC help with the Ads Agent in AMC

Ads Agent in AMC, Amazon Ads’ AI-powered ads partner, is available in AMC to enable advertisers to develop SQL queries more efficiently. The Ads Agent in AMC skills transform complex business questions into actionable SQL queries through natural language conversations, reducing time-to-value while maintaining the precision that sophisticated analysis requires.

Updated on Mar 30, 2026

You can use the Ads Agent in AMC for:

- **SQL generation for audience creation**: Advertisers can generate SQL queries for custom audience creation through natural language conversation. Ads Agent in AMC understands AMC's signals structure and audience capabilities, enabling users to quickly translate business requirements into executable queries, reducing development time from weeks to hours.
- **Analytics SQL query generation:** Enables advertisers to transform business questions into SQL queries through AI-guided exploration and query development. Ads Agent in AMC helps users discover relevant use cases, understand how to best use signals available in AMC, and generate optimal SQL analytics queries for their specific needs.
- **AI-powered user assistance and support**: Advertisers can access immediate answers to AMC product questions through Ads Agent in AMC's intuitive, conversational interface. This includes instant guidance on best practices, feature capabilities, and technical documentation, which simplifies the learning process and increases productivity.

## Locate the Ads Agent in AMC within AMC

To access Ads Agent in AMC in AMC:

1. Log into your AMC account. Learn how to access AMC
2. Click “**Ask AI for AMC help**” on top navigation bar. This is available from any page in AMC.
3. Alternatively, opening the Query editor and click “**Generate SQL with AI**”.

The Ads Agent in AMC chat allows you to:

- Learn about AMC use cases, concepts, and features.
- Ask follow-up questions to refine generated queries.
- Request query revisions.
- Copy generated SQL code directly to your clipboard.
