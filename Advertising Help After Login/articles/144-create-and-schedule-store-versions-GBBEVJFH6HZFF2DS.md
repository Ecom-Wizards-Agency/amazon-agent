# Create and schedule Store versions

You can create multiple versions of your Store and schedule them to run during specific periods of time.

Updated on May 1, 2024

Versioning and scheduling Stores is available when you have an approved store. If you're creating a store for the first time, visit how to Create your Store. For inquiries related to your Store byline, visit Stores byline.

Consider the following when creating and scheduling store versions:

- You’ll always have a live version of your store that has no end date.
- When you create a new version with an end date, it will override the version with no end date for the duration of the new version. You can’t have 2 or more versions with end dates that overlap.
- If you create a new version with no end date, it overrides your existing version with no end date based on the start date you select.
- To see the schedule of your live, approved, and scheduled Stores, click **Show dates of current versions**.
- Modifying or rescheduling an approved version will require you to create a new version and submit it again for review and approval. The moderation review process is usually completed within 24 hours, but it may take up to 3 business days. Learn more about Stores moderation.
- You can cancel the publication schedule of an approved version by clicking the gear icon and following the prompts.
- Once your store is approved, it’s not possible to roll back to a previous version of your store. However, if the version isn’t approved yet you can click **Cancel publishing** to keep your current version of the store.
- The Store Builder requires a default version to always be present and we use the default version to create new versions of the store. We don’t allow the deletion of this default version.

## Create and schedule a new version of an existing Store

1. Click the **Version** drop-down menu at the top of the page.
2. Click **Create new version**.
3. Enter a name for the new version.
4. Select an existing version to use as a starting point for the new version. The existing version won’t be affected.
5. Click **Create version**.
6. Wait until the new version is created.
7. Click **Edit now** to make changes on the new version. Learn about Edit Store pages.
8. When you’re done editing, click **Submit for publishing** on the top-right corner. The new version of your Store will be reviewed.
9. Select the start and end date for your new version.
10. Click **Submit**.

## View the status, cancel the scheduling, or delete a version

1. Click the **Version** drop-down menu at the top of the page.
2. Click the gear icon on the version that you want to modify.
3. Apply and confirm your changes.

## Modify a scheduled or live version

1. Select the version that you want to modify.
2. Click any element that you want to modify.
3. On the pop-up window, select whether you’d like to copy your version to create a new version, or cancel the scheduling and edit the existing version. For versions with no end date, you can only copy to a new version.
