# Amazon Marketing Cloud privacy

Learn how Amazon Marketing Cloud (AMC) prioritizes privacy and security by design.

Updated on Nov 19, 2025

AMC prioritizes privacy and security by design in several ways. AMC doesn’t allow any user-level or event-level information to be exported from AMC. The Amazon Ads records in an AMC instance (impressions and related events such as clicks and conversions) are keyed to a pseudonymized identifier that can’t be extracted from the clean room. AMC applies columns-level sensitivity thresholds and numerous privacy protections to ensure that AMC doesn’t allow egress of any user-level or event-level information.

Essentially, you can’t export Amazon Ads tables from AMC, and all reports generated by AMC are aggregated with a minimum threshold. This means that no rows in a report with dimensions will ever be representative of a group that has less than a predefined minimum number of users, as required by the sensitivity level of the selected dimension. To understand more about AMC’s aggregation thresholds, visit Aggregation thresholds. Additionally, any audiences created in AMC must exceed 2,000 records and can’t be exported from the system; rather, they’re distributed directly to Amazon DSP.

AMC accepts only pseudonymized information, such as hashed email. When first-party (1P) records are uploaded, they’re resolved to the same common, pseudonymized identifier as other records in AMC; 1P identifier values are discarded. Note that while the 1P identifier values are dropped, the table’s schema as shown in the AMC UI will still list the column names, but these columns can’t be used in your queries. This is true for any 1P schema that includes identifier fields. For more details on 1P uploads to AMC, visit AMC data upload. For more information 1P use cases and how to join to Amazon tables, visit First-party signals in AMC.

All information in your AMC instance is handled in strict accordance with Amazon’s privacy notice. Amazon doesn’t access advertiser-owned instances, any 1P records uploaded to AMC, or any of the advertiser-created queries used to create aggregate reports or custom audiences.

These measures ensure that AMC remains privacy-safe while still providing advertisers with the ability to leverage these signals to better plan, activate, and measure across their Amazon Ads campaigns.
