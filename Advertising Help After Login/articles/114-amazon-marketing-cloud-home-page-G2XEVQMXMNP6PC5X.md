# Amazon Marketing Cloud Home page

The Amazon Marketing Cloud Home page provides quick access to Insights templates, use cases, recent activity, and AMC news.

Updated on Aug 11, 2026

When you sign in to AMC, the **Home page** is your starting point. It gives you quick access to **Insights templates**, your favorite use cases, recent activity, and the latest AMC news.

## Home page components

The AMC Home page includes the following sections:

**Welcome banner.** The welcome banner provides links to introductory AMC resources, including an introduction to AMC and the Partner Directory.

**Insights.** The**Insights**section displays pre-built analytics templates, called **Insights****cards**, that you can run directly from the Home page. Each card represents a common analysis such as path to conversion by campaign groups, time to conversion, or overlap by campaign groups.

**Note**: Running a query from an**Insights card** opens the query editor with a pre-populated template. Query execution in AMC does not incur additional charges.

From an**Insights card**, you can:

- Click **Run with your data** to open the query editor with the Insights template pre-populated. You can run the query as-is or modify it to suit your needs.
- Click **Add insight** to add an Insights template to your Home page so you can run it on a recurring basis.
- Click **Edit layout** to customize your Home page by rearranging or removing Insights cards.

**Use cases.** The **Use cases section** shows your favorite use cases and a list of common AMC use cases. Select a use case to open it in the use case library, where you can review instructions and sample queries.

**Where you left off.** This section has 2 parts:

- **Recent projects.** The **Recent projects** section shows your recent activity. Select a project to see more.
- **What's new in AMC?** This is a news and updates section that shows recent AMC announcements and feature updates.

## Customize your Home page

You can personalize your AMC Home page by adding, removing, and rearranging **Insights card**s.

**Add an Insight to your Home page**

1. On the AMC Home page, go to the**Insights** section.
2. Click **Add insight**.
3. Select the**Insights template**you want to add.
4. The template appears as a new card on your Home page.

**Edit your Home page layout**

1. On the AMC Home page, click **Edit layout**.
2. Rearrange Insights cards by dragging and dropping.
3. Delete an Insight by clicking the trash can icon in the upper righthand of the card.
4. Save your changes.

**Run an Insight with your data**

1. On the AMC Home page, locate the **Insights card**you want to run.
2. Click **Run with your data**.
3. The query editor opens with the**Insights template** pre-populated.
4. Review the query and modify it as needed, or click **Submit** to execute it as-is.
5. View your results in the**Projects tab**once the query completes.

## Navigation from the Home page

The navigation menu at the top of the page provides access to all tabs in the AMC UI:

- **Use cases.** Explore top use cases for AMC from a repository of Amazon-authored SQL queries and solutions to help you leverage common measurement and analytics use cases.
- **Query editor.** Use the AMC query editor to author and run SQL queries.
- **Projects.** See a list of all analytics and audience queries submitted from the query editor, and filter by **Status**and**Type**.
- **Audiences.** Create custom audiences that can be activated and used in and sponsored ads.
- **Paid features (beta).** Provides options for deeper analysis of your audiences, campaigns, and outcomes.
