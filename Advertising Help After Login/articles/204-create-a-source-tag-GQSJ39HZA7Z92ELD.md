# Create a source tag

When you’re using your Store as the landing page for your advertising and marketing activities, you can use source tags to understand the traffic coming to your Store.

Updated on May 1, 2024

A source tag is a URL parameter, ?channel=tag-name, that you can add to any Store page URL. When a customer visits your Store using a URL that contains a tag, we detect the tag, and attribute the visit and any resulting metrics to that tag. We then categorize this information for you by tag name in Stores insights, giving you greater granularity of metrics by source. Learn more about Stores insights.

To create a URL parameter and tag-name, consider the following:

- Use only numbers, letters, dashes, spaces, and underscores in your tag name.
- Don’t use any other special characters.
- The limit of the tag name length is 20 characters.
- Use only the lower-case **channel** for the parameter as the upper-case **Channel** isn’t supported.

**Tip:**Create unique source tags to understand the traffic and sales generated from your different advertising and marketing activities. Using source tags, you can create a custom URL that has its own unique identifier for each traffic source.

There’s no limit on how many tags you can create, and tags don’t expire. However, there’s a limit as to when tagged sources are shown by individual tag in Stores insights. Only the top 100 tags that meet a minimal number of visits in the time range viewed will be compiled in Stores insights. Data collected from tags that don’t meet the above criteria will be aggregated under **Other tags**.

**To create a tag using our tag creation tool:**

1. Go to **Stores**.
2. Click **View Insights** of the Store that you want to tag.
3. Click **Create source tag**.
4. Under the **Destination page**, select the Store page for which you want to create a custom URL.
5. Enter your tag name.
6. Click **Copy link** to copy the page link with your added tag.
7. Use the link that you created with the relevant ad or marketing campaign.

**To create a tag manually:**

1. Copy the Store URL that you want to use, and paste it into a location where you can edit it. A Store can be navigated using more than 1 type of URL, but only the following URLs are supported with tags:
  1. A vanity URL, such as https://www.amazon.com/<your store name>.
  2. A URL that starts with https://www.amazon.com/stores/page.
  3. A URL that starts with https://www.amazon.com/stores/<your store name>.
2. If the Store URL that you copied has a **“?**”, delete anything after the **“?**”.
3. Define and create the tag that you want to add. For example, if the tag name is **SummerDresses**, the tag will be ?channel=SummerDresses.
4. Add the tag to the end of the Store URL, without any spaces.
