## Question

A variation started showing a piece count on the detail page that the seller had not submitted. A sibling thread had a unit count used for the per-count price that would not update until Amazon pushed it through.

## Answer

If a detail page shows a pack or piece count you never submitted, first check the value you submitted, then open a Seller Support case with a screenshot and the correct value and ask catalog support to correct the attribute; in the agency's experience editing the listing alone does not clear it. For per-count pricing, give the intended unit count and unit count type for each variation. Amazon states that Selling Partner Support cannot edit a contribution made by another authorized user of a Brand Registry brand; that case goes through Report Abuse instead.

## Cause

Not established from a first-party source. The agency's view is that Amazon adds count attributes from its own data and automated inference, which the seller's own edit does not override; Amazon's detail page rules say an automatic system chooses the displayed value when several contributors supply an attribute. In both threads a Seller Support case got the value corrected.

## Fix

1. Capture a screenshot of the wrong count on the detail page and note which variation shows it.
2. Check the seller-submitted unit count and unit count type for that SKU in the listing editor.
3. Open a Seller Support case asking catalog support to remove or correct the count, stating the correct value and that the seller never submitted the shown one (operator approval needed before sending).
4. When a count attribute drives the price-per-count display, state the intended unit count type per variation in the case so support applies the right value.
5. Reference an earlier resolved case on the same attribute when one exists; follow-ups go faster.

## Verify

The detail page no longer shows the wrong count, and the price-per-count display matches the intended unit count.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
