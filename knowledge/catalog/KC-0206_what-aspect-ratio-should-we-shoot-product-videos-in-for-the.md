## Question

A brand owner hiring a freelance videographer asked which video sizes to brief for the listing product video, the Premium A+ video and a full-width Brand Store video, and whether formats other than 16:9 are possible because 16:9 suits the listing gallery poorly.

## Answer

Listing product videos accept horizontal 16:9 and vertical 9:16 (MOV or MP4, up to 1080p, under 5 GB), so 16:9 is a safe default there but not the only option. Premium A+ video modules and Store video tiles have their own specifications, and Store tile ratios change with the tile size, so check each placement's spec before the shoot instead of assuming 16:9 fits everywhere. Shoot long and in high resolution so the editor can cut each placement's version.

## Cause

The agency answer was to shoot everything in 16:9 and not worry about length because it can be cut. Amazon's shoppable video guide accepts both horizontal 16:9 and vertical 9:16 for product videos, so 16:9 is not the only option there. For Stores, the image size, video resolution and aspect ratio vary with the tile size.

## Fix

1. For listing product videos, brief horizontal 16:9 as the safe default and add a vertical 9:16 cut if mobile-first viewing matters; both are accepted per the shoppable video guide (MOV or MP4, up to 1080p, under 5 GB).
2. For Premium A+ video modules, check the module specification in A+ Content Manager before the shoot.
3. For a Brand Store video tile, check the specification for the chosen tile size in the Store builder, since it varies by tile.
4. Shoot long and in high resolution so the editor can cut lengths and crops per placement afterwards.

## Verify

Each delivered file passes the upload check for its placement without a format or aspect-ratio rejection.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
