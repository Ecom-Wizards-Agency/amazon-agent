## Question

The brand side asked whether the default subscription delivery frequency shown on the detail page can be set from the backend.

## Answer

Sellers cannot set the default delivery frequency for Subscribe & Save; customers pick it on the detail page. Sellers control the funded discount tier, enrollment and Subscribe & Save coupons, so put effort there.

## Cause

Sellers can set the Subscribe & Save discount tier and enrollment, but the delivery frequency is chosen by the customer on the detail page; there is no seller-side default.

## Fix

1. Tell the brand the frequency is a customer choice on the detail page.
2. Use the levers sellers do control: the base discount tier, enrollment and Subscribe & Save coupons.

## Verify

Seller Central Subscribe & Save settings show discount and enrollment options and no frequency setting.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
