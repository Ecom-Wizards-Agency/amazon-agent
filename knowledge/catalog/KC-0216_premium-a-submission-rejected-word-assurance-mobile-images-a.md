## Question

Once Premium A+ became available, the team built premium modules; the uploader needed separate mobile images, a comparison table was added to show the other variants, and Amazon did not accept an image containing the word 'assurance'.

## Answer

Prepare Premium A+ with a mobile version of every image, sized to the module's stated mobile spec rather than reused desktop files. Keep warranty, guarantee and assurance wording out of images and text, because the A+ guidelines exclude it and review rejected 'assurance'. A comparison chart of same-brand sibling variants is allowed and useful.

## Cause

Premium A+ modules take separate desktop and mobile images, and the A+ Content guide lists warranty and guarantee information as not allowed; review rejected 'assurance' as guarantee wording. The exact rejection message is only in a screenshot.

## Fix

1. Check that the brand shows the Premium A+ option in A+ Content Manager before designing premium modules.
2. Deliver desktop and mobile versions of each premium image; the MAG design SOP gives 600 x 450 minimum for most premium mobile images (the team used 1200 x 900), so check the size each module states.
3. Optionally add a comparison chart of same-brand sibling variants, using attributes that are true for each product.
4. Remove warranty, guarantee or assurance wording from images and text before submitting.
5. Submit (operator approval), wait for approval and check the content on the live detail page on desktop and mobile.
6. When a claim in the content changes, update the image and resubmit (operator approval).

## Verify

The A+ content shows as live on the detail page on both desktop and mobile.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
