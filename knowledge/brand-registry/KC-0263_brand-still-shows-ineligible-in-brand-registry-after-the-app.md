## Question

After submitting a Brand Registry application, the brand stayed marked ineligible for more than a day. Clicking Appeal only led back to the existing case, and Support had confirmed that infringement notices could still be submitted.

## Answer

A Brand Registry application can stay ineligible after submission while Amazon runs Rights Owner Verification. Reply on the application case asking what is still needed, and ask the trademark correspondent or attorney of record whether Amazon sent a verification code; return any code on the case within 10 days. In the source case approval followed about a day after the verification notice, without a confirmed code.

## Cause

The application was in Amazon's Rights Owner Verification step. Amazon may email a verification code to the trademark correspondent, often the attorney of record, and the code must be returned on the application case within 10 days. Whether a code was sent in this case was not established; approval arrived about a day after the verification notice.

## Fix

1. Wait about 24 hours after submission, then recheck the status.
2. If still ineligible, reply on the application case (copy the text, do not send only a screenshot) asking what information or steps are needed to restore eligibility. Sending needs operator approval.
3. When Support says Rights Owner Verification has started, ask the trademark attorney of record whether Amazon sent a verification code.
4. Return any code on the application case within the deadline, with the case ID, from Brand applications.
5. Wait for the approval message; tools become available within about two hours of approval.

## Verify

Amazon sends the approval message and the brand shows as enrolled with tools available.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
