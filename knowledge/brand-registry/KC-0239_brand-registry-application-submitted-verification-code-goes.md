## Question

After submitting a Brand Registry application, the agency waited for approval and asked the client whether any email had arrived; the client had to ask its lawyers for the code.

## Answer

Before submitting a Brand Registry application, warn the client that Amazon may send a verification code to the trademark correspondent on record, usually the attorney, rather than to the seller. Get the code forwarded quickly and reply to the application case with it within 10 days, then add further trademarks once the brand is approved.

## Cause

During verification Amazon may contact the trademark correspondent or attorney listed in the trademark record, not the seller account, and send them a verification code. Enrollment stays pending until the code is returned in the application case within 10 days.

## Fix

1. Before applying, tell the client the code will go to the trademark contact (often the attorney) and ask them to forward it promptly.
2. Once received, open Brand applications, select the application case ID and reply with the verification code within 10 days (operator approval required).
3. After approval, add any additional trademarks for other marketplaces to the brand.

## Verify

The application shows approved and the brand appears in Brand Registry.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
