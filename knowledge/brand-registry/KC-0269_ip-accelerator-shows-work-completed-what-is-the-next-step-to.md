## Question

The trademark filing through IP Accelerator showed the status "work completed" and the brand owner asked what to do next.

## Answer

A "work completed" status from the trademark firm does not mean the brand is enrolled in Brand Registry. Enrol the brand with the pending application number, ask the firm to forward any verification code Amazon sends them, and reply to the application case with the code and case ID within 10 days. The thread did not confirm what the firm's status means.

## Cause

Not fully established in the thread, which only says the trademark firm should have a code to enter in Brand Registry. Per the Brand Registry pages, a pending trademark filed through IP Accelerator makes the brand eligible, and after the application is submitted Amazon may send a verification code to the trademark correspondent or attorney, which the brand returns on the application case.

## Fix

1. Ask the trademark firm for the pending application number and confirm the filing went through IP Accelerator.
2. In Brand Registry, click Manage > Enroll a brand and enrol with the pending application number.
3. If Amazon sends a verification code to the firm, get it from them, click the application's case ID on the Brand applications page and reply within 10 days with the code and the case ID.

## Verify

The brand application status on the Brand applications page moves to approved.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
