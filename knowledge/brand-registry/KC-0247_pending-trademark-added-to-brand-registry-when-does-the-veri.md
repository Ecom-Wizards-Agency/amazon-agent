## Question

The brand owner added a pending national trademark to Brand Registry while the trademark office had raised no objections, and the agency asked whether a verification code was needed yet.

## Answer

No verification code is needed when you submit a pending trademark to Brand Registry. Amazon reviews first and may then ask for ownership verification. For a new enrolment the code goes to the trademark contact and you return it on the application case within 10 days; for a trademark added to an enrolled brand you copy the code from the Requests tab and the correspondent confirms it within 30 days.

## Cause

Per the Brand Registry application process page, Amazon verifies trademark ownership after submission and may send a verification code to a contact on the trademark record; no code is entered at submission. The thread does not say whether this was a new enrolment or a trademark added to an enrolled brand, and the add-trademark verification works differently.

## Fix

1. New enrolment: in Brand Registry, click Manage > Enroll a brand and give the pending application number; the brand name must match the trademark text.
2. Wait for review (status Pending review). If Amazon contacts the trademark correspondent or attorney, get the code from them and reply to the application case with the code and case ID within 10 days.
3. Trademark added to an enrolled brand: use Manage > Manage intellectual property > Connect a trademark. If Amazon asks for ownership verification, open the Requests tab, click Confirm ownership, copy the code and email it to the trademark correspondent, who has 30 days to confirm.

## Verify

New enrolment: the application moves from Pending review to Approved. Added trademark: it moves from the Requests tab to the Connected tab.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
