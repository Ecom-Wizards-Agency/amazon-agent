## Question

A client preparing a trademark filing asked whether Amazon needs a particular route: register the plain brand name as a word mark, or register the logo, which the client considered easier to defend.

## Answer

For Brand Registry the choice between a word mark and a logo mark does not matter, as long as the logo contains the brand name as words, letters or numbers that match the application. A design-only logo without text is not accepted for initial enrollment and can only be added after the brand is enrolled. Pick the mark type on legal grounds and check that its text matches the brand name exactly.

## Cause

Brand Registry accepts either a text-based word mark or an image-based design mark that contains words, letters or numbers, as long as the trademark text matches the brand name in the application. Only design-only marks and logos without readable text are refused for initial enrollment.

## Fix

1. Confirm the planned filing either is a word mark or is a logo that contains the brand name as readable words, letters or numbers.
2. Make sure the text in the mark matches the brand name you will enter in the Brand Registry application.
3. If the client wants a pure symbol or design-only logo, file a word or text-bearing mark for enrollment and add the design-only mark after the brand is enrolled.
4. For an image-based mark, keep a copy of the image exactly as it appears in the trademark record for upload during enrollment.

## Verify

The Brand Registry application accepts the trademark registration or pending application number and the brand name matches the mark text.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
