## Question

The agency found several listings that look like counterfeits of the brand plus many similar unbranded products, and asked the brand owner for evidence to take the counterfeits down. The brand owner asked whether one order covering all suspect listings is fine.

## Answer

Before reporting a counterfeit, complete a test buy and keep the order ID plus photos of the box and product, because Amazon asks for the order number when you report a trademark or copyright violation. Place one order per suspect listing, particularly for seller-fulfilled offers, so each piece of evidence maps to one listing and seller. Do not file trademark reports against unbranded look-alikes that never use your mark.

## Cause

A counterfeit or trademark report is far stronger with a test buy: the order ID proves the purchase and photos of the received box and product show the brand mark misused. Unbranded look-alikes that do not use the trademark are not trademark infringement and do not qualify for a trademark takedown.

## Fix

1. Sort the suspect listings: keep those that use the registered brand name or logo; set aside unbranded look-alikes, which are not trademark infringement.
2. Place a test buy for each suspect listing as a separate order, especially when the offer is seller-fulfilled, so each order ID ties to one listing and one seller.
3. When the items arrive, photograph the outer box, the packaging and the product showing the misused mark.
4. File the report in Brand Registry (Report a violation, or the Project Zero self-service tool if enrolled) and enter the test-buy order ID in the order ID field with the photos attached. Operator approval required before submitting.

## Verify

The reported offers are removed or the report status in Brand Registry shows an outcome; record the report ID against each order ID.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
