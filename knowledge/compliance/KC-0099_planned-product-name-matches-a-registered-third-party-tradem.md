## Question

Before launch, the client noticed no competitor used the planned model name for the product and suggested removing it; the agency checked the trademark register.

## Answer

Search every planned product or model name in the trademark register before it goes into a listing. If another party has registered it, drop the name rather than using a near-identical spelling, and fall back to keyword-led titles like the competition. Bring in the client's IP lawyer when the name matters to the brand.

## Cause

The planned name was a registered word mark owned by a third party, so using it in the listing risks a trademark complaint and listing removal.

## Fix

1. Search the planned product or model name in the national trademark register for the marketplace (for the US, the USPTO) and record the mark's status and registration date.
2. If someone else has registered the mark, ask the brand's IP lawyer before using the name.
3. Do not use a near-identical spelling to get around the mark; it invites the same dispute.
4. Check how competitors title the product; if none use a model name, drop the name and build the title from matching keywords instead.

## Verify

The live title and listing content carry no third-party registered mark, and the IP lawyer's view is recorded.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
