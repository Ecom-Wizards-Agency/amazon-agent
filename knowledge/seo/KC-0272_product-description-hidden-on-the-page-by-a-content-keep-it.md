## Question

A reviewer flagged a listing's plain-text product description as keyword stuffing; the SEO specialist noted it does not show on the page because A+ content replaces it and suggested keeping it.

## Answer

A+ content hides the plain-text product description from shoppers, but do not delete the field. Amazon's A+ Content page calls it best practice to keep A+ changes reflected in that field in Manage Your Inventory. Hidden text is still listing content, so it must follow the detail page rules and pass the compliance review.

## Cause

Published A+ content hides the plain-text product description on the detail page, but the field still exists in the listing, and Amazon advises keeping it in line with the A+ content.

## Fix

1. Keep the plain-text product description populated even when A+ content is live.
2. Write it as clear customer-facing copy that carries the same details as the A+ content, and remove any claim the compliance review flags. Do not use the hidden field as a keyword dump.
3. When A+ content changes, update the plain-text description in Manage Your Inventory to match.

## Verify

The listing's product description field is populated, matches the current A+ content, contains no flagged claims, and the detail page shows the A+ content.

## Stop before

Stop before any submission, appeal, case send, refund, price change or listing change unless the operator approved that exact action.
