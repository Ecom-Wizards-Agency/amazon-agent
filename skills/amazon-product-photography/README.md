# Product photos and photo prompts

Use this skill for packshots, lifestyle, usage and detail photos, targeted edits,
selective enhancement, or ready-to-run prompts with explicit reference roles.
FLORA is preferred; the selected model and connected provider determine execution.

> Use $amazon-product-photography with these product photos and lighting references.
> Prepare three FLORA photo prompts: a packshot, a lifestyle scene and a detail shot.

Use the selective design installation in `docs/design-skills-installation.md`
of the Amazon Agent repository. No full operator setup,
POE files, listing copy or Figma access is required. Prompts work without provider
connections; generation requires the selected provider's authorized connection.

`SKILL.md` in this Amazon Agent skill directory is the canonical source. The references contain model guidance, provider research and a small
photo input pack. This skill delivers photos, not listing graphics or typography.
