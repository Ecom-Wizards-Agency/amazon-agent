# Listing image concepts and copy

Use this skill with product facts and POE exports to prioritize buying motives,
plan a useful image sequence, and write the exact headline, optional subheadline,
optional USPs and visual direction for each image.

> Use $amazon-listing-images with these product facts and POE files. Marketplace:
> Germany. Copy: English. Deliver image concepts, order, exact copy and visual briefs.

Use the selective design installation in `docs/design-skills-installation.md`
of the Amazon Agent repository. No full operator setup,
Seller Central login, DataDive access or existing ASIN is required. Supplied data
is analyzed with its dates and limitations.

`SKILL.md` in this Amazon Agent skill directory is the canonical source. `references/worked-example.md` explains the reasoning with an anonymized
example. Photography routes to `amazon-product-photography`; Figma layout work is
optional and outside this skill.
