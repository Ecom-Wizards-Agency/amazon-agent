# Amazon Image Production

Browser: Mixed (supplied assets and Figma tools first; required visual-editor work follows the workspace browser standard).

Turn an accepted image brief and photographic assets into finished listing graphics.
This skill owns composition, native typography, graphic elements and editable Figma
layouts. `amazon-product-photography` separately owns generating, editing, enhancing
or prompting the photos. Do not run a generator when suitable photos already exist.

## Intake and scope

Read supplied copy, image jobs, language, count/order, product photos, brand assets
and layout examples. Inspect the examples and extract concrete typography, spacing,
palette, image treatment and information-density choices. A Figma file is needed
for work in that file, not for preparing an independent layout handoff.

If buying strategy or copy is missing and requested, use `amazon-listing-images`.
Do not rerun POE for production alone. If a finished layout requires a missing
photo, use `amazon-product-photography` with the shot requirements and relevant
references. Its provider/model research remains there as the single source.
A photo-only request routes there immediately and does not start Figma work.

## Design and review

Read `references/figma-production.md` and load the applicable Figma tool skills.
Inspect the target file and destination before writing. Protect existing work.
Build one representative frame with native editable text, separately replaceable
photos, and editable shapes or annotations. An imported finished JPEG is not a
fully editable listing layout; photographic pixels remain raster content.

Inspect both rendered screenshots and layer structure, fix observed problems,
then extend the accepted direction through the requested gallery. When a material
style choice remains unresolved, use human feedback on the representative frame.
Do not repeat approval for accepted direction or routine reversible edits.

- Preserve exact copy, variant, quantities, dimensions and claims from the brief.
- Check hierarchy and contrast at mobile size, and crop/artifacts at full size.
- Keep source notes, operational metadata and placeholders outside final exports.
- Verify frame count/order, text contents, editable layers and export dimensions.
- Check applicable current Amazon requirements for production-ready deliverables.

Deliver actual Figma/frame links, previews and requested exports with remaining
retouch or design decisions. If Figma is unavailable, provide a self-contained
layout handoff with assets, exact copy and composition instructions; call it a
handoff rather than an implemented design. Follow workspace storage and artifact
rules. Listing publication and messages remain separate actions.
