# Brand Registry error messages

When you encounter an error on Brand Registry, we request that you take steps to identify the nature of the error prior to contacting support for technical troubleshooting. Not all questions or concerns are technical in nature, even if they might initially appear to be.

The following help topics provide guidance and instructions for the most common Brand Registry error messages.

- Enrollment error messages
- Role assignment error messages
- Report a Violation error messages
- Abusive conduct error messages
