# Amazon Warehousing and Distribution (AWD)

Amazon Warehousing and Distribution (AWD) is a low-cost bulk storage solution for your inventory that distributes to Amazon store and other distribution channels. In addition, the program automatically replenishes your inventory in Prime-ready fulfillment centers.

Users with primary access will be automatically enrolled upon visiting the Amazon Warehousing and Distribution program page.You’ll be charged only when you send your inventory to Warehousing and Distribution facilities. By participating in Amazon Warehousing and Distribution (AWD), you agree to the program’s terms and conditions.

## Get started

To access and use the Amazon Warehousing and Distribution program, go to Amazon Warehousing and Distribution (AWD). From the quick action menu Send inventory to AWD, you can create and send a shipment.

For more information, go to Send shipments to Amazon Warehousing and Distribution (AWD).

## Grant access to users

The Warehousing and Distribution tools are visible only to users who have permissions to use the program. If you don't have the required permissions, the primary account holder for your account can grant them to you via the User permissions page.

The primary account user can grant access by following these steps:

1. Go to User permissions.
2. Add a **new user**, or select an **existing user**.
3. Go to Inventory, then go to **Amazon Warehousing and Distribution– Secondary user access**. Select one of the following three levels of permission.
  - **None**: These users don’t have access to inventory information.
  - **View**: These users can only view inventory information.
  - **Edit**: These users can take actions on inventory.
5. In case you would like to grant accesses for AWD Inventory page as well, select relevant option for **Global FBA Inventory** row as well.
6. To grant access to **AWD Inventory Ledger report**, grant access to ‘**Global FBA Inventory’**permission under ‘**Reports**’ section.
7. Click **Save changes**.
