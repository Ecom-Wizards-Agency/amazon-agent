# Creator Connections Slack Sweep Format

## Daily sweep thread

Create one parent message per brand and date.

Parent message format:

`Brand Name Creator Connections Sweep | Month Day, Day of Week`

Post all updates as replies inside that thread.

## What to include

Include only new updates or status changes.

Do not repeat old updates unless something changed.

Daily categories:

- 🎬 Posted Content
- ✅ Address Confirmed
- 🟢 Priority Sample Lane
- 🟡 Needs Verification
- 🔵 New Inquiries
- 🟣 Product Switches
- ⚫ Paused Product
- 👀 Awaiting Content
- 🧾 Manager Review

## Priority sample lane

Separate creators into:

- Tier A: Ready to action now
- Tier B: Good candidate, but missing one or more items

Tier A should usually have:

- Final ASIN confirmed
- Full name
- Complete address
- Email or phone when available
- Storefront or proof checked
- Recent posting activity verified
- Low spam risk
- Strong qualification score

## Weekly summary

Every Monday, prepare a client-facing summary inside the internal Creator Connections Slack channel.

Keep it concise and organized:

- Campaign activity summary
- New inquiries
- Sample approvals
- Samples sent
- Content posted
- Performance updates
- Creators still awaiting content
- Risks or manager review items
- Next priorities for the week

Do not include unnecessary tracker links unless the operator asks for them.

## Example structure

Parent:

`Brand Creator Connections Sweep | July 30, Thursday`

Thread replies:

`🎬 Posted Content`

`Creator Name posted a video for Product Name. Link: [video link]`

`🟢 Priority Sample Lane`

`Tier A: Creator Name, Product Name, ASIN, score, next action`

`🟡 Needs Verification`

`Creator Name is missing proof of recent content and final ASIN confirmation.`
