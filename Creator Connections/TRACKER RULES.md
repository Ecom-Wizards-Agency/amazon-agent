# Creator Connections Tracker Rules

## Tracker purpose

The tracker is campaign-level, not brand-level. Each tab should represent one campaign, product, or focused campaign group that can be shared with a client.

## Campaign details area

The top area should include:

- Campaign name
- Product name
- ASIN
- Campaign link
- Start date
- End date
- Commission rate
- Campaign notes
- Score legend

The campaign link should appear once in the campaign details area, not repeated on every creator row.

## Creator rows

Each creator row should show enough information for the manager to know:

- Who the creator is
- What product they want
- Whether they are qualified
- What they are missing
- Whether a sample was sent
- Whether content was posted
- What the next action is

## Qualification gate columns

Use these fields when checking whether a creator should move toward sample approval:

- Amazon Storefront Link
- Portfolio or Media Kit Link
- Requested ASIN
- Product Match Status
- Recent Posting Verified?
- Last Visible Post Date
- Content Quality Rating
- Category Fit
- Performance Evidence Available?
- Revenue Threshold Met?
- Specific ASIN Mentioned?
- Spam Risk
- Qualification Score
- Qualification Notes

## Contact and fulfillment fields

Use these fields when a creator moves toward sample fulfillment:

- Full Name
- Street Address
- City
- State or Province
- ZIP or Postal Code
- Phone
- Email
- Fulfillment Method
- Sample Units
- MCF Order ID
- Estimated Fee
- Estimated Ship Date
- Estimated Delivery Date
- Follow-up Date

## Status rules

Use clear statuses with chip colors. Do not leave new statuses uncolored.

Recommended statuses:

- New Inquiry
- First-Base Pass
- Needs Verification
- Proof Requested
- Address Verification
- Sample Ready
- Sample Sent
- Awaiting Content
- Video Posted
- Performance Update
- Manager Review
- On Hold
- Do Not Send
- Product Switch Pending
- Undecided
- Paused Product
- Unqualified

For paused or unavailable products, use a neutral dark gray style.

## Duplicate row rule

Do not keep redundant active creator rows in multiple product tabs.

If a creator changes products:

- Keep one active row under the final product.
- Keep historical notes showing the original requested product.
- Do not move a creator who is still undecided.

## Already sent samples

If a sample was already sent before tightened qualification rules were added:

- Keep the sample status as sent.
- Add the qualification fields as accurately as possible.
- Mark the sample approval exception as waived if needed.
- Continue tracking posted content and performance normally.
